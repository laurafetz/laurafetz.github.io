# Laura Maria Fetz — my personal website

Sometimes I wonder if we're secretly all the same. I use data to find out how we differ, and why.

[Visit my website](https://laurafetz.github.io/)

## A little about the site

This is where I bring together my academic background, research, writing, and a few questions I've explored with data. The questions can be playful; I take the methods seriously.

My academic background includes my degrees at the University of Amsterdam and LMU Munich. The skill tiles open a closer look at my R, Python, and SQL tools, alongside statistical modelling, psychometrics, machine learning, and research practice.

There's a separate section for my internship at Prowise Learn. My research timeline follows three overlapping threads: developmental psychology, single-case research, and intelligence and measurement. It also features my [joint-first-author paper in JAACAP Open](https://doi.org/10.1016/j.jaacop.2025.12.002).

## Built with

HTML, CSS, and JavaScript, hosted on GitHub Pages. There's no build step. My portrait collage inspired the cream, sea blue, sage, and copper colours.

To preview the site locally, run this from the repository folder:

```sh
python3 -m http.server 8000
```

Then open [localhost:8000](http://localhost:8000).

## Comments

Project and writing pages use the free community version of [HTML Comment Box](https://www.htmlcommentbox.com/). Visitors can comment without a GitHub account. The provider's attribution remains visible, and comment configuration is kept in `comments.js`.
